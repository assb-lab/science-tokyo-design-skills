# スライド

出典: [パワーポイントテンプレート](https://design-system.isct.ac.jp/ja/application/powerpoint-templates/)
（テンプレートのデータは学内限定サイトのブランドデータダウンロードにある）

## 公式テンプレートの構成

- サイズは 16:9 と 4:3 の2種類。デザインは **A〜D の4パターン**。1つの資料で混ぜない。
- 書体は游ゴシック（和文・欧文とも）。
- ページの種類: 表紙、中表紙1・2、目次、コンテンツページ（8種）。
- 見本から読み取れる共通の作り（公式の数値規定ではない）:
  - **表紙**: Science Blue の地か白地に、アーチの帯（サブカラー／Science Blue）。タイトルは左寄せの太字、ロゴは隅。
  - **中表紙**: 白地に細い帯を上下に入れ、タイトルを中央付近に置く。
  - **コンテンツ**: 白地。左上にタイトル（Science Blue の太字）と見出し、右上にロゴ、右端に細い縦帯、右下にページ番号。

| パターン | 表紙の印象（見本より） |
|---|---|
| A | Science Blue の地、下側にサブカラーの斜め帯と白い楔 |
| B | 白地、上にサブカラーの帯、下に Science Blue の大きな帯 |
| C | 白地、右下に太いアーチの帯が交差 |
| D | 白地、細いアーチの線が斜めに横切る |

**ユーザーが学内者で公式 .pptx を持っているなら、それを使うのが最善。** Claude/Codex が
ゼロから作る場合は、以下で雰囲気を合わせる。

## HTML（1920×1080）で作るときの型

[assets/slide-template.html](../assets/slide-template.html) に、表紙・中表紙・コンテンツ・
表・図の5枚の雛形がある（内容はダミー）。座標の約束:

| 要素 | 位置・スタイル |
|---|---|
| 余白 | 上下左右 128 px（フッターがあるスライドは下 160 px） |
| 右端の縦帯 | `left:1900px; width:20px; height:1080px; background:#1c3177` |
| 右上の大学名（ロゴの代わり） | `top:56px; right:128px;` Hind 26 px 600、`#1c3177`、文字列「Institute of Science Tokyo」 |
| アイブロウ | 26 px 700 `#435ea5` |
| 見出し | 64 px 700 `#1c3177` |
| 本文 | 26–32 px `#333333` |
| カード | 背景 `#f2f4f9`、上罫線 6 px `#1c3177`、角丸 4 px |
| 強調ボックス | 背景 `#e8eaf1`、左罫線 8 px `#1c3177`、文字 `#1c3177` |
| 表 | ヘッダ行 `#e8eaf1`、罫線 `#cfdbed`、縞 `#f9fbff` |
| 濃色カード | 背景 `#1c3177`、文字 `#ffffff` / 補足 `#cfdbed` |
| フッター | 左下に資料名・発表者（24 px `#595959`）、右下にページ番号（Hind） |

表紙と中表紙の帯は [graphic-elements.md](graphic-elements.md) の SVG を最初の子要素
（背景）として置き、その上に文字を重ねる。

## Claude の Slides artifact（project/slides/*.html）で作るとき

- `deck.json` の `faces` に Noto Sans JP と Hind の Google Fonts リンクを入れる。
- `<section>` の `font-family:'Noto Sans JP', Arial, sans-serif`、英語だけの要素に `'Hind', Arial, sans-serif`。
- 背景の SVG・縦帯は section の最初の子にする（後ろに置くと本文を隠す）。
- インラインスタイルだけで書く（margin・class 不可）。座標は上の表の値をそのまま使える。

## PowerPoint（python-pptx / pptxgenjs）で作るとき

- 書体は「游ゴシック Medium」（太字見出しは「游ゴシック」Bold）。
- 色は上の表と同じ。タイトルは 28–32 pt、本文 16–20 pt（13.33×7.5 in の 16:9）。
- ロゴのプレースホルダーとして右上に空き枠を残し、利用者に公式ロゴを入れてもらう。

## 渡すときに伝えること

- ロゴは入っていない（または大学名テキストで代用した）こと
- 公式テンプレート・ロゴは学内限定サイトから入手できること
- 1つのパターンで統一していること
